2. Event Creation & Moderation (Organizer)

User Flow

Dashboard→ Wizard (4 Steps)→ Publish→ Admin Review→ Approved / Rejected

After publishing, the event enters a "pending" moderation state. An admin reviews and approves or rejects. The organizer is notified by email.

Trigger

3. Event Discovery & Registration (Attendee)

User Flow

Browse Events→ Event Landing Page→ Access Code (if Private)→ Personal Info→ Session Selection→ Confirmation

Events display Public or Private badges. Private events require an access code. Both logged-in users and anonymous guests can register.

4. B2B Networking & Meetings

User Flow

Networking Hub→ Browse Matches→ Connect→ Schedule Meeting→ Confirm / Decline→ Check-in at Meeting

Users can discover AI-suggested matches, send connection requests, and schedule B2B meetings. Meeting emails are sent to both parties at each stage of the meeting lifecycle.
